# deployment-practice

A simple FastAPI app to practice deployment with Docker, PostgreSQL, and HTTPS on a VPS.

## Tech Stack

- FastAPI + Uvicorn
- PostgreSQL + SQLAlchemy
- Docker + Docker Compose
- Nginx (reverse proxy)
- Let's Encrypt (SSL)

## Goals

- Containerize FastAPI app
- Set up PostgreSQL database
- Deploy to VPS
- Configure HTTPS
- Practice production deployment
